FAQ

Masih ada yang ingin ditanyakan?

Beberapa pertanyaan yang paling sering kami dengar dari pemilik usaha.

Butuh bantuan memilih paket?

Hubungi admin untuk bertanya tentang paket dan proses aktivasi.

Chat admin di WhatsApp
Bagaimana cara mengajukan akun?
Isi formulir permintaan akun dan pilih durasi paket. Data Anda akan dikirim ke admin melalui WhatsApp untuk ditindaklanjuti.
Perangkat apa saja yang didukung?
SiCatatin berbasis web dan bisa dibuka dari browser di HP, tablet, maupun laptop. Tidak ada instalasi aplikasi tambahan; cukup masuk dengan akun Anda.
Kapan saya menerima username dan password?
Setelah pembayaran paket dikonfirmasi, admin akan memberikan username dan password untuk masuk ke aplikasi.
Berapa harga paketnya?
Paket mingguan Rp 15.000, bulanan Rp 50.000, dan tahunan Rp 500.000.
Bagaimana cara membayar?
Admin akan menghubungi Anda melalui WhatsApp untuk memberikan arahan pembayaran sesuai paket yang dipilih.
Apakah formulir langsung membuat akun?
Tidak. Formulir hanya mengirim permintaan dan data diri melalui WhatsApp. Admin mengatur akun setelah pembayaran dikonfirmasi.
